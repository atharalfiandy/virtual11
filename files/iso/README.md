# Media ISO Windows 11

Repository ini sengaja tidak menyertakan image ISO Windows. ISO adalah media berlisensi, berukuran besar, dan harus diperoleh oleh pengguna dari sumber resmi Microsoft.

## Langkah aman

1. Unduh media instalasi Windows 11 dari situs resmi Microsoft sesuai lisensi dan wilayah Anda.
2. Verifikasi hash SHA-256 menggunakan nilai yang diterbitkan oleh sumber tepercaya, jika tersedia.
3. Simpan ISO di folder lokal di luar repository, lalu pasang sebagai virtual optical drive melalui hypervisor.
4. Jangan unggah ISO ke GitHub atau membagikan image yang tidak memiliki hak distribusi.

Gunakan `iso-checklist.json` sebagai daftar pemeriksaan. Folder ini hanya menyimpan dokumentasi dan metadata, bukan ISO.
