MULAI DI SINI

Checklist setup

4 langkah
  1. 01
    Pilih hypervisor

    Gunakan VirtualBox, VMware, Hyper-V, atau QEMU/KVM yang sudah terpasang.

  2. 02
    Siapkan ISO resmi

    Unduh ISO Windows 11 dari situs Microsoft. ISO tidak disertakan dalam repository ini.

  3. 03
    Atur VM

    Gunakan contoh konfigurasi di config/vm-defaults.json sebagai titik awal.

  4. 04
    Boot dan instal

    Pasang ISO ke virtual optical drive, lalu ikuti installer Windows.
